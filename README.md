# Controle de Treino - Musculação Feminina

Aplicação web e PWA de acompanhamento de treinos para hipertrofia com foco em tríceps (5 sessões por semana: Treinos A, B, C, D e E).

🔗 **Link Permanente da Aplicação:**  
[https://jvafonso32-png.github.io/fichabruna/](https://jvafonso32-png.github.io/fichabruna/)

---

## 📱 Recursos
- **Mobile First / iPhone**: Layout em cards otimizado para uso na academia, teclados numéricos diretos e botões rápidos.
- **Divisão A-B-C-D-E**: Preservada integralmente com metas, tempos de descanso e exercícios.
- **Sugestão de Progressão**: Análise automática de cargas e repetições (regra 3x8 com RIR 1-2).
- **Cronômetro Integrado**: Marcador de tempo de descanso com alerta sonoro e vibração.
- **Autenticação e Nuvem (Firebase)**: Salva dados no Google Cloud Firestore com sincronização em tempo real e cache offline para academias sem sinal.
- **Backup Local**: Exportação e importação de arquivo `.json`.
